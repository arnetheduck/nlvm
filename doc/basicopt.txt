::

    nlvm command [options] [projectfile] [arguments]

Command:
  //compile, c                compile project
  //cc                        compile C/C++ files like clang (passthrough)

Arguments:
  arguments are passed to the program being run (if --run option is selected)

nlvm specific options:
  --nlvm.target:triple      use a specific target triple, for example
                            arm-linux-gnueabihf or wasm32-unknown-unknown -
                            this will override --os: and --cpu:!
  --nlvm.bpf.entry:name     exported Nim procedure to place in the BPF
                            program section (required to build BPF programs)
  --nlvm.bpf.section:name   ELF section the BPF program is placed in, for
                            example xdp (must differ from the entry name)
  --nlvm.bpf.license:text   license string for the `license` ELF section, for
                            example GPL; omitted means proprietary
  --llvm-<opt>              pass opt to the llvm command line parser - see
                            --llvm-help for available options

  BPF targets are selected with --cpu:bpf|bpfel|bpfeb or with a matching
  --nlvm.target triple. Compiling one requires --nlvm.bpf.entry and
  --nlvm.bpf.section, defaults to --opt:size when no --opt flag is given,
  expects fixed-width integer types for the BPF ABI and requires global
  initializers to be compile-time constants.

Options:
  -p, --path:PATH           add path to search paths
  -d, --define:SYMBOL(:VAL)
                            define a conditional symbol
                            (Optionally: Define the value for that symbol,
                            see: "compile time define pragmas")
  -u, --undef:SYMBOL        undefine a conditional symbol
  --threads:on|off          turn support for multi-threading on|off
  -x, --checks:on|off       turn all runtime checks on|off
  -a, --assertions:on|off   turn assertions on|off
  --opt:none|speed|size     optimize not at all or for speed|size
                            Note: use -d:release for a release build!
  --debugger:native|endb    use native debugger (gdb) | ENDB (experimental)
  --app:console|gui|lib|staticlib
                            generate a console app|GUI app|DLL|static library
  -r, --run                 run the compiled program with given arguments
  --fullhelp                show all command line switches
  -h, --help                show this help

Note, single letter options that take an argument require a colon. E.g. -p:PATH.
